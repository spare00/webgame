# Web Game

## Development

```sh
npm install
npm run dev
```

Contra is the first game migrated to Phaser and TypeScript. Build all game pages with `npm run build`.

## Neon Memory

Open `memory.html` from the home menu. Match eight pairs using clicks or Tab + Enter/Space. The timer starts on the first flip. Restart resets the board and cancels pending flips. Run behavioral tests with `node --test tests/memory.test.mjs`.
